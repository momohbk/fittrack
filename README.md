## ✨ Key Features

- **AI Workout Plans** — Personalized training programs generated based on goals, equipment, and experience
- **Progress Tracking** — Visual charts for weight, measurements, reps, and body composition
- **Nutrition Logger** — Barcode scanning with 500k+ food database and macro tracking
- **Social Challenges** — Compete with friends with leaderboards, streaks, and achievements
- **Exercise Library** — 1000+ exercises with video demos, form tips, and muscle group targeting
- **Wearable Sync** — Connect Apple Watch, Fitbit, and Garmin for automatic activity tracking

## 🛠 Tech Stack

| Layer | Technology |
|-------|-----------|
| **Frontend** | React 19, TypeScript, Tailwind CSS, Recharts |
| **Backend** | Firebase (Auth, Firestore, Cloud Functions) |
| **Database** | Firebase Firestore |
| **Storage** | Firebase Storage (profile images, workout photos) |
